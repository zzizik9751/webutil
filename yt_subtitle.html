유튜브 자막 받기

유튜브 영상의 자막(자동 생성 포함)을 화면에서 읽고, SRT/TXT로 저장합니다. 영어 등 외국어 자막은 한국어로 자동 번역합니다.

1. 설치 (한 번만)

  1. 북마크바가 안 보이면 Ctrl+Shift+B로 켭니다.
  2. 아래 버튼을 마우스로 끌어 북마크바에 놓습니다.

    ▶ 자막 받기

끌어다 놓기가 안 되면: 아래 [코드 복사] → 북마크바 우클릭 → 페이지 추가 → 이름 "자막 받기", URL 칸에 붙여넣기.

2. 사용법

  1. 유튜브 영상 페이지를 엽니다 (PC 크롬·엣지).
  2. 북마크바의 자막 받기를 누르면 오른쪽에 자막 창이 뜹니다.
  3. 표시 방식: 한국어 번역 / 원문 + 한국어 / 원문만
  4. 자막 줄을 누르면 그 위치로 이동, 재생 따라가기를 켜 두면 현재 줄이 강조됩니다.
  5. SRT 저장(시간 포함, 동영상 플레이어용) · TXT 저장(읽기용 문단) · 복사
  6. 창은 제목줄을 끌어 옮기고, 오른쪽 아래 모서리로 크기 조절, 다시 누르면 닫힙니다.

"자막을 받지 못했습니다"가 뜨면 영상의 자막(CC) 버튼을 한 번 켠 뒤 [다시 시도]를 누르세요. 다른 영상으로 넘어가면 창을 닫고 다시 누릅니다. 번역은 유튜브 자동 번역이라 전문용어는 어색할 수 있습니다.
