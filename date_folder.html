Date Folder

파일의 최종수정일을 기준으로 월·주·연·일 폴더를 만들어 정리합니다. 모든 파일 형식 지원
  • 폴더 선택 후 위쪽 옵션을 바꾸면 폴더별 요약과 파일 목록 미리보기가 바로 갱신됩니다. 파일 목록에서 개별 파일은 체크로 제외할 수 있습니다.
  • 이동은 수정일을 그대로 유지하는 방식을 먼저 시도합니다. 브라우저가 이를 지원하지 않으면 안전을 위해 중단하며, 수정일 변경 허용을 켜면 복사 후 원본 삭제로 처리하되 이때 파일 수정일이 현재 시각으로 바뀝니다. 복사 모드의 복사본도 수정일이 현재 시각이 됩니다.
  • 같은 이름의 파일이 있으면 이름 뒤에 (1)을 붙여 덮어쓰지 않습니다.
  • 되돌리기는 방금 실행한 이동을 원래 폴더로 되돌립니다(창을 닫으면 사라집니다). 중요한 파일은 먼저 백업하세요.
